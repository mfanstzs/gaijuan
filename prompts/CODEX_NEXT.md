# 后续阶段提示词

把下面的 M1 换成要执行的实际阶段。一次只指定一个阶段。

```text
继续 DeskGrade，只执行 docs/TASKS.md 的 M1。

先读 AGENTS.md、docs/STATUS.md 和本阶段任务卡，确认上一阶段真实完成情况。
涉及状态机、评分契约和桌面动作时，读取对应文档后再修改。
先报告当前差距和本次文件范围，然后实现并测试；不重复生成大方案，不擅自增加功能。

保持原有架构，不引入教师复核台，不回到整卷上传流程。
禁止为通过测试而删除用例、降低断言或用固定 true 代替平台确认。
不要自动操作真实学校平台或调用未授权的付费 API。

结束更新 docs/STATUS.md，报告真实测试与未测项，然后停止。
```

# 修 Bug 提示词

```text
修复下述问题，只做最小必要修改：
【粘贴复现步骤、期望结果、实际结果与脱敏日志】

先定位并增加失败回归测试，再修实现。不得顺便重构无关模块。
状态机、配置版本、提交闸门和数据契约的原有不变量必须保留。
修复后运行相关测试与默认 verify，更新 STATUS，列出实际未执行的 Windows/真实平台验证。
```
