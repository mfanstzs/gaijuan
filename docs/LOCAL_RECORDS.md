# 本地评分与调用记录

从 0.2.2 起，默认数据目录固定为 `%USERPROFILE%\.deskgrade\data`（例如 `C:\Users\你的用户名\.deskgrade\data`）。数据不在安装目录中，同一 Windows 用户从桌面快捷方式或开发工具启动，默认使用这一处记录。

此前已确认：Codex 的 MSIX/AppData 虚拟化环境与正常桌面启动，可能把旧的 `%LOCALAPPDATA%\DeskGrade` 解析到两处不同的实际目录。“换一种方式启动后记录看不到”不一定是记录已删除，也可能是读取了另一处数据库。新版本改用上述稳定用户目录，避免继续分成两套历史。

下表路径均相对于新的默认数据目录：

关闭或重启软件不会清空历史。打开“记录”页会自动查询本机持久记录，默认不限日期、批次或状态；启动尚未完成时打开记录页，也会在本地数据就绪后重新查询。可以点“查询”更新结果，或用“重置筛选”查看全部历史。读取失败会明确报错，不当作“没有记录”。

| 位置 | 用途 |
| --- | --- |
| `database/local-deskgrade.mv.db` | H2 权威本地账本：评分点、学生转写、用量、耗时、规则快照、动作和提交事实；记录页直接查询 |
| `records/grading-YYYY-MM-DD-NNNNNN.jsonl` | 每行一个 JSON 的摘要，含时间、批次/答卷/调用 ID、模型、状态、得分、Token、耗时和受限错误码 |
| `performance/performance-YYYY-MM-DD-NNNNNN.jsonl` | 0.2.3 起每份答卷的性能摘要：总耗时、互斥主阶段、模型等待、截图次数/耗时、填分/读分/提交与存储细项；仅本机保存 |
| `logs/deskgrade.jsonl` 等 | 运行和故障日志，保留 7 天并受 100 MB 总量轮换限制，不等于完整评分账本 |
| `settings/local-profiles.json`、`local-model-selection.json` | 无 Key 的模型配置及角色选择 |
| `credentials/*.dpapi` | 当前 Windows 用户加密 Key 缓存，不是学生记录，不随安装包分发 |

评分 JSONL 每段最多 16 MiB，每个事件最多 16 KiB，按本机日期分段，不自动删除历史；异常退出留下的残行保留，后续用新段，不篡改旧行。H2 与日志都同步写入，任一写入失败都会阻止后续动作。它们不是跨文件原子事务；写入一边后另一边失败仍保留已写证据并停止，不能据此补交。

完整数据库与 `records` 下的评分/调用摘要不受 `logs` 的 7 天运行日志轮换影响。运行日志滚动清理不等于清空评分历史，也不能用运行日志代替完整数据库备份。

`performance` 是独立辅助诊断，不是提交账本，也不受 7 天运行日志轮换影响。每份在完成切换、停止或暂停时聚合写一行，避免每次截图都刷盘；写入失败只产生安全告警，不会重试提交或改变评分。实际账本与 `records` 的存储失败仍按原规则停止。分阶段说明及查看方法见 [耗时日志说明](LOCAL_PERFORMANCE_TIMING_20261021.md)。

规则生成与文本能力验证以工具调用事件写入本地 JSONL，不创建虚构的学生答卷。图像能力验证使用合成数字图，不使用真实学生图片。

记录页从本地数据库读取完整评分和提交事实；JSONL 是便于文本查看和排障的逐行摘要，不是只放在内存里的列表，也不包含恢复完整学生答案所需的全部数据。仅保留 JSONL、删除数据库后，不能从摘要重建完整详情或重新授予自动提交权限。备份时应一起保留数据库和 JSONL。

JSONL 不接收图片、原始 HTTP 正文、Key 或任意异常文本。H2 和主动导出的 JSON/CSV 会含学生 OCR、逐点依据、标准答案及模型配置等隐私；配置的 credentialRef 是引用名，不是 Key。Key 加密并不意味着学生数据库也已加密，请谨慎分享并做好本地磁盘保护。

新截图只在内存使用，记录保留哈希与时间等元数据。旧记录的历史文件引用不表示应用会重新打开、上传或重评旧图片。

## 升级与迁移

升级保留已有本地数据。迁移以备份和保留原件为前提；如果新目标已存在，不会用旧文件覆盖。程序遇到迁移残留、来源不明确、复制或校验失败等异常时，会显示错误并停止启动，不会悄悄新建一个空库让历史看起来消失。遇到提示请保留原目录和备份，核对来源后再处理，不要先删除数据库。

本机此次整理已在备份后将现有数据复制到稳定目录，正常桌面和 Codex 虚拟化环境的两处旧数据均保留。这是对现有使用电脑的单独处理，不表示通用安装包携带这些数据或 Key；也不是把服务器历史导入本地，不会自动合并云端记录。

备份请先完全退出 DeskGrade，再复制整个 `%USERPROFILE%\.deskgrade\data`，同时保留数据库、`records`、`settings` 和需要留存的加密凭据。Key 缓存依赖原 Windows 用户的解密环境，不能作为给其他用户或其他电脑分发 Key 的方式；换环境时应重新填写自己的 Key。

云端旧记录不在新本地数据库中：保留原归属，需要时另行只读导出归档；不自动查询旧服务器，不迁移或删除历史未知提交，也不自动补交。
