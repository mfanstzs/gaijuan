# DeskGrade 本地 BYOK 版（0.2.6）

本版本启动即进入工作区，没有 DeskGrade 登录、注册、充值、次数套餐或账号余额。每位安装者输入自己的模型 Key；安装包不包含所有者或服务器的 Key。

新安装默认使用千问模板，评分规则生成默认 `qwen3.8-max`，不再默认选择 OpenAI。已有配置的用户可在向导第一步直接复用本机相同供应商的配置和有效验证；原生效用途直到最后确认才改变。顶部网址框初始为空，浅色提示为“请在此打开评分网站”，不预填测试地址。

主评分、备用评分、评分规则生成由本机直接调用配置的模型接口。网页截图、身份核验、规则校验、求和、填分读回、提交/换卷判断均由本机完成，不需要 DeskGrade 服务器、MySQL 或 Redis。模型不是离线模型：答卷会发给你选择的供应商，供应商费用和限流仍然存在。

配置与角色在“模型与 Key”页管理：默认只展示三张用途状态卡，需要修改时打开四步流程，依次选择用途/供应商、填写模型与 Key、验证能力、确认启用。高级接口设置默认收起；编辑和取消不自动切换生效用途，修改后的配置先独立保存为草稿。Key 用当前 Windows 用户 DPAPI 缓存；安装目录中不写 Key。新安装默认模型模板未验证，需填写并验证自己的 Key。已有有效本机验证可沿用，不重复调用；主/备用评分要求图像与结构化验证，规则生成可只验证文本结构，不伪造图像能力。

评分规则生成使用已经生效的规则生成模型及其 Key，不再因为其他尚未启用的模型草稿、编辑中的阅卷模型或未保存的用途选择而被锁住。生效模型自身未配置、缺少 Key、验证无效或当前操作不允许时，仍会阻止调用；灰色按钮可悬停查看具体原因，不会绕过验证或自动发起收费请求。

0.2.5 加强评分口径一致性：明确零分条件不能被笼统“宽松”或中间分绕过，部分分需对应具体已满足/未满足要求；新生成规则需说明分值边界，不改变已保存规则。输出优先简洁但保留必要语境；声明清晰空白却给出实际学生证据的矛盾结果会按既有无效结果路径处理，不自动补零或改历史分数。实际准确率仍须同卷人工定标核对。

“本次阅卷数量”仍保留，属于任务停止条件而非收费额度。防 A/B 串分、严格截图核验、异常立即停止、未知提交不补交、冻结原图的单次备用，以及已确认未发送正文时的 3 次总连接尝试/20 秒间隔都保留。

自动阅卷仅在等待模型评分时，在用户手工框选的答题区显示粉色边框和上下扫描线。扫描只是本机界面提示，不修改网页，不抢占焦点或拦截点击。所有真实截图前会清除动画并等待画面呈现确认；清除失败则停止截图，不通过放宽像素校验继续。暂停、停止、切换或关闭目标窗口会清除扫描提示。

0.2.3 增加逐份本地耗时日志，自动保存在 `performance/*.jsonl`：区分页面等待、截图、模型往返、填分、读回、提交和换页，另记截图次数及编码等细项。0.2.4 据此精简评分解释中的重复表述，并仅在新截图原始像素逐一完全相同后复用 PNG 编码；完整作答转写、所有评分点、防串分、输入/提交校验及稳定等待均保留。新增编码/复用次数与像素比较耗时，真实速度及评分效果须用下一批实际答卷对照。详见 [耗时日志说明](LOCAL_PERFORMANCE_TIMING_20261021.md)。

新评分数据存本机 `database/local-deskgrade.mv.db` 与 `records/*.jsonl`，相对于固定的 `%USERPROFILE%\.deskgrade\data`。完整详情在本地数据库，按日期分段的 JSONL 是调用与评分摘要；二者都不受 7 天运行故障日志轮换影响。初始化完成后自动读取全部本机历史，读取异常单独提示，不伪装为零条；重启不删除记录，也不能只凭 JSONL 摘要还原完整学生详情。详细内容见 [本地记录](LOCAL_RECORDS.md) 与 [模型配置](LOCAL_MODEL_SETUP.md)。

已查明旧目录分离的原因是 Codex/MSIX 的 AppData 虚拟化与正常桌面运行访问了两处实际数据目录。此次现有使用电脑的数据在备份后复制到稳定用户目录，原两处旧数据均保留；这是本机单独处理，不包含在通用安装包中。后续升级仍按保留优先处理：目标已存在则不覆盖；迁移异常会弹窗并停止，不会回退成空库启动。旧云端配置、数据库和服务器记录不删除、不自动导入、不续跑，也不要求关闭现有服务器。

本地数据与程序安装目录分离，升级前应退出并备份整个用户数据目录。修改网页/生效模型配置或重启后须重新框选。安装包仍不包含本机数据或 Key；本包尚未代码签名，不能把本地合成测试等同于任意真实网站已经通过验收。
